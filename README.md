# Aims Community College: Selected Coursework

Selected projects from my **Associate's degree in Computer Information Systems** at Aims Community College (January 2023 to May 2025, Dean's List), including work toward my **C# Programming**, **Full-Stack Web Development** and **Object-Oriented Mobile Programming** certificates.

These are class projects, so they're smaller than my professional work, but together they show the range of languages and fundamentals behind it. For production projects, see my [portfolio](https://kyrasdigitalsolutions.com/portfolio.html).

## Running the projects

- **C#:** open the `.sln` file in Visual Studio.
- **C++:** open the `.sln` file in Visual Studio, or compile the `.cpp` files with any C++ compiler.
- **Java:** compile and run the `.java` files with the JDK, or open the folder in an IDE.
- **JavaScript:** open the `.html` file in a browser.
- **Kotlin and Android:** open the project folder in Android Studio.
- **SQL:** run `movies.sql` in MySQL to create the database, then try the statements in `queries.sql`.
